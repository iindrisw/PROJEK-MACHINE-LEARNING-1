Deskripsi Dataset
Dataset yang digunakan berasal dari UCI Machine Learning Repository yaitu Student Performance (khususnya data mata pelajaran Portuguese / student-por.csv). Dataset ini terdiri dari 649 baris dan 33 kolom tanpa adanya missing value maupun data duplikat.
Tautan Sumber Dataset: UCI Student Performance Dataset
Kolom Target: G3 (Nilai akhir/final grade siswa dalam rentang 0-20)
Fitur yang Digunakan: G1, G2, studytime, absences, failures, Medu, address, dan higher.
